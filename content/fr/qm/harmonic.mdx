## L'oscillateur harmonique

L'oscillateur harmonique quantique est le problème lié canonique : une particule dans un potentiel quadratique

$$V(x) = \tfrac{1}{2} m \omega^2 x^2$$

Les niveaux d'énergie sont quantifiés :

$$E_n = \hbar\omega\left(n + \tfrac{1}{2}\right), \quad n = 0, 1, 2, \dots$$

L'état fondamental a pour énergie $E_0 = \tfrac{1}{2}\hbar\omega$ — l'énergie de point zéro, effet purement quantique.
